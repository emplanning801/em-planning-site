# 株式会社EM PLANNING 公式サイト

GitHub Pagesでそのまま公開できる静的サイトです。

## ページ構成

- `index.html` — HOME
- `service.html` — SERVICE（4事業領域）
- `sales-support.html` — 既存営業代行LPを活かした営業支援詳細
- `about.html` — ABOUT
- `company.html` — COMPANY
- `contact.html` — CONTACT
- `privacy.html` — プライバシーポリシー

## 公開方法

このディレクトリの内容をGitHubリポジトリの `main` ブランチへ反映すると、既存のGitHub Pages設定から公開できます。

独自ドメイン `em-planning.co.jp` へ切り替える際は、GitHub PagesのCustom domain設定とDNS設定を行い、各HTMLのOGP URLおよび `sitemap.xml` のURLを新ドメインへ変更してください。
